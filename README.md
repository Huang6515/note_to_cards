# note_to_cards

Markdown 课程笔记转智能复习提纲与自测卡片

## 项目简介

`note_to_cards` 是一个将 Markdown 格式的课程笔记自动转换为智能复习提纲与自测卡片的工具。帮助学习者从大量笔记中快速提炼重点，并通过自测卡片进行主动回忆式复习，提升学习效率与记忆效果。

## 功能特性

- 解析 Markdown 课程笔记，提取章节结构、标题等级与正文内容
- 自动生成结构化复习提纲（核心概念、关键术语、公式与结论）
- 将要点转换为问答形式的自测卡片，支持自我测验与评分
- 输出格式灵活，可导出为文本、Markdown 或导入主流卡片记忆工具

## 快速开始

```bash
# 克隆项目
git clone https://atomgit.com/gcw_iWzhhlWn/note_to_cards.git

# 使用示例（示例命令，具体以项目实现为准）
python note_to_cards.py your_notes.md -o review_outline.md -c cards.md
```
